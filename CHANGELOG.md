# Changelog

## 0.2.0 — 2026-11-09

First public release of the independently developed OpenFilm Harness bridge.

- Ten MCP tools for editor opening, context, references, commands, guarded edits, receipts, undo, frame checks, rendering and idle shutdown.
- Conversation/project bindings when a real host session ID is supplied; explicit connection scope otherwise.
- Revision checks, locked-track protection, persistent edit receipts and idempotent request handling.
- Separate editor-page and control credentials with origin checks.
- Codex/Claude compatibility manifests, local marketplaces, Gemini descriptor and configuration printers.
- Windows installer, portable collaboration Skill and bundled-dependency release archive.
- Public English/Chinese setup documentation and retained synthetic-project tests.

The underlying local 0.2.0 implementation was accepted on Windows on 2026-11-06. See [validation scope](docs/VALIDATION.md) for host and runtime limits.
